# robosuite object assets

The `bottle`, `can`, and `cereal` MJCF models and their referenced meshes and
textures were copied without modification from
[ARISE-Initiative/robosuite](https://github.com/ARISE-Initiative/robosuite)
at commit `5ce6643f3092639d08f7b0f90ed1c6a84f50552c`.

The source files are under `robosuite/models/assets/objects` and
`robosuite/models/assets/textures` in that repository. See [LICENSE](LICENSE)
for the upstream MIT license.
